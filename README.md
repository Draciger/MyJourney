# MyJourney

A collection of school projects and assignments completed during my Bachelor's in Data Science at Høyskolen Kristiania. Each folder contains work from a different subject, with its own README explaining the tasks and findings.

---

## 📁 Uploaded Work

### 📊 [Visual Analytics](./VisualAnalytics)
Data visualization and dashboard design using Tableau. Explores two datasets — Company X sales data and the UN World Happiness Report — extracting business and social insights through interactive dashboards.

### 🐍 [Python](./Python)
Data analysis and programming tasks using Python and Pandas. Covers exploratory data analysis, building DataFrames from scratch, and real-world price analysis using Nord Pool electricity market data.

### 📈 [Predictive Analytics](./PredictiveAnalytics)
Time series analysis and forecasting of electricity load using VAR and ARIMA models, with stationarity testing and model evaluation.

### 🤖 [ML & NLP](./ML_NLP)
Machine learning and natural language processing tasks covering classification, clustering, regression, spam detection, and a content-based movie recommendation system.

### 🧠 [Deep Learning](./DeepLearning)
CNN experiments on the MNIST dataset comparing data augmentation, learning rate schedulers, and optimizers. Also includes a group exam project on medical image segmentation using the Kvasir-SEG polyp dataset.

### 🏃 [Agile Project](./AgileProject)
A full-stack web application built for Peers — a real-time voting and scoring platform for live events. Developed over four weeks using a Google Design Sprint and three Scrum sprints, with an AI-assisted event setup flow powered by Google Gemini.

### 💻 [Software Design](./SoftwareDesign)
A console-based game tracker called **CoverBox** built in C# with SQLite. The project focuses on clean architecture across three layers (UI → Business Logic → Data Access) and applies key software design principles including SOLID, Repository pattern, Facade, and Dependency Injection. Includes refactoring work and NUnit automated tests.
